# HULL-ION Materials Workbench

Open index.html in a current Chrome, Edge, Firefox, or Safari browser.
No installation or login is needed for this offline bundle.

- Explore: Search 6,228 archival candidate structures and export filter results.
- Compare: Select up to four records. Bookmarks are stored in the browser when supported.
- Validation: Inspect the 20 reported structures, their CIFs, verified local DFT–NEB paths, 0 K metal-reference bulk assessments, and benchmarks.
- Screening lab: Replay the four archived threshold criteria, or use the included CSV template to upload/enter your own predictions. Input stays in the browser.
- Data: See data/snapshot-manifest.json. Respect the terms of the originating structure databases.

This is a static research release. The site does not predict properties for newly uploaded CIFs or launch DFT jobs.
