# Data sources and attribution

The HULL-ION workbench contains a curated research snapshot. The candidate records preserve their originating database and exact source ID. The site publishes the project's screened list, screening indicators, and validation summaries, not source-database dumps. The listed source terms apply to the original records and structures; no single blanket license is asserted for the combined snapshot.

| Source | Reference | Scope in this workbench |
| --- | --- | --- |
| Materials Project (MP) | Jain et al., *The Materials Project: A materials genome approach to accelerating materials innovation* ([paper](https://doi.org/10.1063/1.4812323); [dataset and CC BY 4.0 statement](https://doi.org/10.17188/1693272)) | Source IDs and selected records; 13 hosted CIFs (ranks 1, 5, 7, 8, 9, 12, 13, and 15–20). |
| Materials Cloud MC3D PBEsol-v2 | Huber, Minotakis, Bercx, Reents, Eimre, Paulish, Hörmann, Uhrin, Pizzi & Marzari, [MC3D archive](https://archive.materialscloud.org/records/szjaf-cfv74), CC BY 4.0 | Four hosted CIFs (ranks 2, 6, 10, and 11). |
| NIST JARVIS-DFT | Choudhary et al., [JARVIS-DFT 3D dataset](https://doi.org/10.6084/m9.figshare.6815699), CC BY 4.0 | Two hosted CIFs (ranks 3 and 14). |
| Crystallography Open Database (COD) | Gražulis et al., [COD](https://www.crystallography.net/cod/); [CC0 policy](https://www.crystallography.net/cod/documents/topic/privacy/COD-privacy-GDPR.pdf) | One hosted CIF (rank 4; ID 1510917). |
| AFLOW | [AFLOW](https://aflow.org/) | Candidate references and HULL-ION screening records; no original CIFs hosted. |
| Alexandria | [Alexandria database](https://alexandria.icams.rub.de/) | Candidate references and HULL-ION screening records; no original CIFs hosted. |
| OQMD | [Open Quantum Materials Database](https://oqmd.org/) | Candidate references and HULL-ION screening records; no original CIFs hosted. |

The hosted CIFs are the copies used in this project's archived candidate set. Formatting and filenames may differ from the source databases. The viewer renders atomic positions and unit cells from those CIFs without inferring bonds. The [Creative Commons Attribution 4.0 license](https://creativecommons.org/licenses/by/4.0/) applies where identified above. Values computed by HULL-ION and the accompanying benchmark statistics are attributed to the [HULL-ION project](https://github.com/ahvsjags/hull-ion).
